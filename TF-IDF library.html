텍스트 속에서 중요한 단어를 찾아보세요. 줄바꿈 한 줄이 하나의 문서가 되어, 문서별 TF와 전체 IDF를 함께 계산합니다.

분석할 텍스트

여러 문서를 비교하려면 문서마다 한 줄씩 입력하세요. 한 줄만 쓰면 하나의 문서로 분석됩니다.

한글·영문·숫자 단어를 인식합니다

계산 기준

같은 단어라도 여러 문서에 흔하면 중요도가 낮아집니다.

TF · 해당 문서에서 단어가 나온 횟수
IDF · ln((문서 수 + 1) / (단어 포함 문서 수 + 1)) + 1
TF-IDF · TF × IDF

추가로 제외할 단어를 입력하세요. 쉼표, 공백, 줄바꿈으로 구분합니다.

형태소 분석: 조사와 대표 어미를 분리해 결과를 원형으로 묶습니다. 예: “시작이었다” → “시작이다”, “공부했다” → “공부하다”. 규칙 기반 분석이므로 전문 형태소 분석기와 결과가 다를 수 있습니다.

TF-IDF 계산 연습

각 문장과 형태소 조합의 값을 직접 입력하세요. TF는 해당 문장의 빈도, DF는 해당 단어가 등장한 문서 수입니다. IDF는 화면의 스무딩 공식을 사용하며, 소수 넷째 자리까지 입력하면 됩니다.
문장형태소TFDFIDFTF-IDF
값을 입력한 뒤 결과 확인하기를 눌러 주세요.
계산 방식: IDF에는 0으로 나누는 문제를 피하고 한 문서뿐인 경우에도 비교 가능한 값을 주기 위해 스무딩을 적용했습니다. 표는 TF-IDF가 높은 순으로 정렬됩니다.
